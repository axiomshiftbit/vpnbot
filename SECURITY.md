# Безопасность / Security

**Не публикуйте уязвимости в открытых issue.** Сообщите о проблеме приватно:
вкладка **Security → Report a vulnerability** этого репозитория (GitHub Private
Vulnerability Reporting). Укажите версию (коммит), шаги воспроизведения и
возможные последствия; не прикладывайте реальные токены, ключи и адреса серверов.

**Do not report vulnerabilities in public issues.** Use **Security → Report a
vulnerability** (GitHub Private Vulnerability Reporting) of this repository.
Include the commit, reproduction steps and impact; never attach real tokens,
keys or server addresses.

Поддерживаются ветки `master` (stable) и `dev`. / Supported branches: `master`
(stable) and `dev`.
