VPNBot snolc 0.0.4+vpnbot.3 — SSH + Noise

Нативный клиент: Linux x86_64 с glibc и Python 3.11 или новее.
Распакуйте архив в отдельную личную папку. Профиль содержит секрет доступа.

В ZIP включён client-patches.zip: ядро и все модули (SOCKS5, SSH, Noise,
policy-local) собраны VPNBot из закреплённых исходников; из архивов выпуска
берутся только лицензии. Установка не скачивает файлы
с GitHub; целостность компонентов проверяется по закреплённым SHA256.
Установка модулей с проверкой SHA256 и исправлений, проверка конфигурации:
    python3 client.py --install --prepare

Запуск:
    python3 client.py

SOCKS5 слушает только 127.0.0.1:1080. TCP и UDP приложений передаются
внутри одного SSH-транспорта; отдельный внешний UDP-порт не нужен.
Доступ к локальным и приватным сетям сервера запрещён.
Пример проверки (DNS разрешается на сервере):
    curl --socks5-hostname 127.0.0.1:1080 https://example.com/

Другой локальный порт: python3 client.py --socks-port 1085
После изменения адреса, порта или личного ключа скачайте новый архив.
При зависшем переподключении запускатель перезапускает ядро через 20 секунд;
проверка ключей сервера остаётся обязательной.
Оба ключа сервера закреплены в профиле; не отключайте их проверку.
Используйте свежую резервную копию бота для переноса сервера с прежними ключами.

Это конфигурационный архив VPNBot, а не JSON для sing-box или Mihomo.
Текущий snolcNG не переносит SSH pin при импорте ссылки: готовый импорт
этого режима в Android/iOS и snolcNG не заявлен. GUI-клиент не требуется
для приведённого запуска через нативное ядро snolc.

SSH-транспорт имеет собственный узнаваемый SSH-баннер. Он не имитирует
HTTPS и не гарантирует неотличимость от OpenSSH или обход конкретного DPI.
Исходники: https://github.com/owenewans/snolc
Модули: https://github.com/owenewans/snolc-modules

Исправления VPNBot устраняют утечки закрытых потоков, освобождают UDP после
закрытия SOCKS5-соединения, отправляют последний UDP-кадр без ожидания
другого трафика и снижают расход CPU в простое. Не заменяйте
комплект клиента исходными бинарными файлами 0.0.4.

Версия 0.0.4+vpnbot.3 увеличивает интервал пустых опросов до 10 мс,
включая простой с открытым соединением; при передаче данных ожидание
сбрасывается. Также исправлен порядок кадров при одновременном открытии
потоков: данные больше не опережают команду открытия и не рвут туннель.
При заполнении внутренней очереди отправка ждёт свободного места,
чтобы не терять крупные UDP-пакеты при параллельной передаче.
Если остатка текущего резерва трафика недостаточно для UDP-пакета,
резерв пополняется сразу; общий лимит пользователя продолжает действовать.
После обновления сервера скачайте свежий ZIP и повторите
python3 client.py --install --prepare, чтобы обновить также локальное ядро.
Профиль, порт и ключи доступа сохраняются; клиенты vpnbot.2 совместимы
с новым сервером, но сохраняют прежний расход CPU и ошибки параллельной
передачи на клиентской стороне. Для всех исправлений обновите также
клиентское ядро.
