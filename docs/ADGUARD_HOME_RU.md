# Обновление AdGuard Home с 0.107.80 до 1.0.0

AdGuard Home 1.0.0 при первом запуске переводит конфигурацию VPNBot со схемы 34 на схему 35. Новый интерфейс входит в образ. Настройки DNS, списки и правила фильтрации, клиенты и учётные записи продолжают храниться в прежнем YAML. Перед обновлением сохраните штатную резервную копию VPNBot.

## Возврат к 0.107.80

Бинарник 0.107.80 отклоняет YAML со значением `schema_version: 35`. Перед возвратом к прежнему комплекту подготовьте текущий YAML для старой версии. Так сохранятся и изменения, сделанные после перехода на 1.0.0.

В корне установки задайте `OLD_AD_IMAGE` равным ссылке на образ `ad` с digest из манифеста предыдущего выпуска. Пока скрипт из нового комплекта доступен, остановите процессы, которые могут писать конфигурацию, и проверьте преобразование старым бинарником.

```sh
docker compose stop service php ad
docker run --rm --network none \
  -v "$PWD/config:/config" -v "$PWD/certs:/certs:ro" \
  -v "$PWD/scripts/adguard_rollback_config.sh:/rollback.sh:ro" \
  --entrypoint sh "${OLD_AD_IMAGE:?Укажите образ ad предыдущего выпуска}" \
  /rollback.sh /config/AdGuardHome.yaml
```

Для конфигурации VPNBot преобразование меняет только верхнеуровневое поле версии схемы. Скрипт проверяет временный файл бинарником 0.107.80 и заменяет YAML атомарно только после успешной проверки. Затем верните прежний комплект штатным способом и запустите службы. При отказе проверки сохраните текущий комплект и исходный YAML для разбора.
